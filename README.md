# SmartMarketer

小红书新媒体工作台。当前版本由浏览器运行，草稿保存在当前站点的浏览器存储中。

## 本地开发

需要 Node.js 和 Python 3。无需安装 npm 依赖。

```sh
npm run dev
```

浏览器访问 http://127.0.0.1:4175/ 。修改源码后刷新页面。

## 构建与部署

```sh
npm run build
npm run preview
```

在 http://127.0.0.1:4176/ 预览构建产物。部署时把 `dist/` 的全部内容上传到 Nginx 等静态站点服务的站点根目录，入口为 `index.html`。生产服务器只需提供静态文件，Node.js 和 Python 3 用于本地构建与预览。

AI 出稿、飞书、数字人与剪辑当前为演示入口。草稿按访问地址隔离，原先通过文件地址保存的草稿不会自动出现在 HTTP 地址下。
